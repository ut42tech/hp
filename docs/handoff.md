### 3. 本人に確認したいこと

- **インターンの終了月**: 素材に無かったので、終了月を開始月と同じにした。「BrightJ 長期インターン 2023.05」のように、1か月だけに見える。
- **外部リンクの「↗」**: 設計書では外部リンクに付けることになっている。ただ、Figma の Press カードと SNS ボタンには付いていない。どちらに合わせるかを決める。

### 4. 後回しにした不具合と改善

最終レビューで見つかった細かい点。どれも公開を止めるほどではない。

- **表示の切り替え**: アイコンが「自動」で描かれてから正しいアイコンに変わる。ライトかダークを選んでいると、ページを移るたびに一瞬ちらつく。
- **詳細の「戻る」**: 詳細を閉じると履歴が1つ増える。閉じたあとにブラウザの「戻る」を押すと、詳細がまた開く。シートの動きと一緒に直す。
- **フォント**: LINE Seed JP の CSS が重く（gzip 後で約 211KB）、最初の描画を止める。分割や絞り込みを検討する。
- **ヘッダー**: 幅 1024〜1130px では、透明なヘッダーがスクロールした中身に重なる。
- **細かい点**:
  - Skills のタイルのリストの意味づけ（`li role="img"`）
  - アクセシビリティのテストが浅い
  - Skills の一覧が2か所にある
  - 長い名前の省略がない
  - 言語の切り替えのスクリプトがインラインで書いてある
- **セキュリティレビュー**: 途中で API の回数制限（HTTP 429）にかかり、終わっていない。公開前にやり直す。

## 作業するときの注意

- **`vp`**: グローバルの `vp check` が `@astrojs/compiler-rs` を見つけられないことがある。`vp run check` か `pnpm exec vp check` を使う。
- **テスト**: `apps/web/test` はビルド結果（`dist`）を読むので、先に build する。
- **開発サーバーと Tailwind**: 新しく作ったファイルの Tailwind のクラスは、開発サーバーを再起動するまで効かないことがある。
- **Astro のスコープ付き CSS**: どのレイヤーにも入らないので、Tailwind のユーティリティより強い。スコープ付きで `display` を決めた要素では、`max-lg:hidden` などが効かない。表示の出し分けは部品の CSS に書く。
- **`vite.config.ts`**: ルートの `@vitejs/plugin-vue` は `as unknown as PluginOption[]` でキャストしている。Vite の型が2つ入っていて、TS2321 になるため。
- **LinkedIn**:
  - アイコンは `simple-icons-11`（`simple-icons@11.0.0` の別名）から読む。最新版の Simple Icons から外されたため。
  - URL は末尾のスラッシュ無しにしている（`packages/profile`）。
- **公開リポジトリの扱い**:
  - 旧サイトの素材の `private/` には個人情報と API キーがある。リポジトリに入れない。
  - 設計書などに、参考にしたサイトの名前を書かない。
