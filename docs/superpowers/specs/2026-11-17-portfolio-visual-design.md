# ポートフォリオ 見た目（ビジュアル）設計書

- 日付: 2026-11-17
- 対象: `apps/web`（ut42tech.com）の見た目と動き
- 範囲: Figma の変数・部品・主要画面を、本番の見た目に仕上げるところまで。あわせて、動きの値を数値で決める。コードでの実装は別の計画で扱う。
- 前提: 画面の構造は [`2026-11-16-portfolio-wireframe-design.md`](2026-11-16-portfolio-wireframe-design.md) で確定している。本書はその上に見た目を載せる。

## 1. 目的と背景

第一印象で、**歓迎されている感じ**と「これからワクワクするものが見られる」期待感を出す。本人の細部へのこだわりは、**言葉ではなく見た目と手触りで**伝える。派手さよりも、自然さと気持ちよさを優先する（構造の設計書 3 章の原則と同じ）。

登場演出、Hello のあいさつ、吸い付くポインター、すりガラスの素材は、使い捨ての試作で手触りを確かめた。本人の評価は「めちゃくちゃ UX いい」。本書の動きの数値は、その試作の値を書き写したもの。

## 2. ゴール / 非ゴール / アンチゴール

### ゴール

- Figma の変数（ライト／ダーク）が本番の値になっていて、`packages/tokens` の `--ut-*` にそのまま移せる。
- 主要な画面が、スマホとパソコンで本番の見た目になっている。
- 動き（登場演出、あいさつ、ポインター、押したときの反応）が数値で決まっていて、実装者が迷わず再現できる。

### 非ゴール（今回はやらない）

- Hello の 3D と AI エージェント。エージェントを作るときに一緒に作る（本人の決定）。それまでは、タイポグラフィのあいさつで代える。
- コードでの実装と、`packages/tokens` の値の差し替え。
- 実際の作品写真・文章の用意。仮の画像と文章でよい。

### アンチゴール（できても失敗とみなすもの）

- UI に色が付いて、**作品の写真やサムネイルが目立たなくなる**こと。
- 演出のせいで**待たされる**と感じること。
- 文字が背景に溶けて**読めない**こと。WCAG AA を下回るコントラストは不可。
- 既存のサイトやテンプレートの**模倣に見える**こと。OS の部品を描き写すこと。

## 3. 決まったこと（本人と合意済み）

- **全体はモノトーン。アクセントの色は持たない。** 色は作品のアイコン・サムネイル・写真に集中させる。
- **書体は LINE Seed JP。** 等幅は Geist Mono（日本語の字を含む箇所は LINE Seed JP）。
- **Hello はタイポグラフィのあいさつ**: 大きな「Welcome.」と、小さな「to ut42tech」。
- **登場演出**: 幕の上に「Takuya Uehara」を小さめに出してから、幕が上がる。
  - 本名は About の中だけ、という構造の設計書の決まりは、この演出についてだけ例外にする（本人の決定）。
- **パソコンのポインター**: iPad のようにボタンへ吸い付く。OSS の [ipad-cursor](https://github.com/CatsJuice/ipad-cursor)（MIT）を使う。
- **素材**: タブバーとツールバーに、すりガラス（透け感と光の縁）を使う（試作で確認）。シートは文字やカードを読む場所なので、すりガラスにせず `color/surface` の不透明な面にする（Claude の判断。読みやすさを優先）。

## 3.1 細部の決め（実装前の確認で Claude が決めたこと）

- **Hello の画面**: `bg` の上に「Welcome.」と「to ut42tech」だけを置く。3D の領域は今は取らない。ただし、将来のエージェントの入力欄のために、スマホではタブバーの上に余白を残す（構造の設計書 10 章）。シートの上端から覗くのは、Hello の地と「Welcome.」の上端。
- **ライト／ダークの切り替え**: OS の設定に従い、手動でも切り替えられる（今のコードの仕組みを引き継ぐ）。切り替えボタンはパソコンではツールバーの右端に置く。スマホでは Hello をすっきり保つため、About の一番下（連絡先の後）に「表示: 自動／ライト／ダーク」として置く。
- **アイコン**: タブバーとツールバーの切り替えは、試作のとおり文字だけにする。小さな操作（戻る「‹」、外部へ開く「↗」、並び替え、表示の切り替え、メールのコピー）にだけアイコンを使う。アイコンは [Lucide](https://lucide.dev)（ISC ライセンス）から選び、線の太さは 1.75 にそろえる。OS のアイコン（SF Symbols など）は使わない。
- **並び替え**: メニューは出さず、押すたびに「新しい順／古い順」が入れ替わる1つのボタンにする（試作のとおり）。ラベルは今の並び順を表す。

## 5. 色（Claude の提案。モノトーンの範囲で決めた値）

Figma のコレクション `ut42tech`（モード Light / Dark）を、次の値に作り直す。キャンバス案の名残であるカーソル4色（`color/cursor/*`）と `color/on-cursor`、`color/grid-dot` は消す。

| Figma 変数 | `--ut-*` | Light | Dark | 役割 |
| --- | --- | --- | --- | --- |
| `color/bg` | `--ut-color-bg` | `#F4F4F3` | `#111112` | ページの地 |
| `color/surface` | `--ut-color-surface` | `#FFFFFF` | `#1C1C1E` | カード・シートの面 |
| `color/fg` | `--ut-color-fg` | `#141414` | `#F2F2F2` | 文字・選択中の面 |
| `color/muted` | `--ut-color-muted` | `#6B6B6B` | `#8D8D92` | 補足の文字 |
| `color/border` | `--ut-color-border` | `#E3E3E3` | `#2C2C2E` | 罫線・カードの枠 |
| `color/fill` | `--ut-color-fill` | `#000000` 7% | `#FFFFFF` 10% | 押せる面の地・ホバー |
| `color/placeholder` | `--ut-color-placeholder` | `#ECECEB` | `#232325` | 画像がないときのフォールバックの面 |
| `color/glass` | `--ut-color-glass` | `#FFFFFF` 62% | `#262628` 55% | すりガラスの面 |
| `color/glass-edge` | `--ut-color-glass-edge` | `#FFFFFF` 90% | `#FFFFFF` 14% | すりガラスの上端の光 |
| `color/glass-line` | `--ut-color-glass-line` | `#000000` 8% | `#FFFFFF` 8% | すりガラスの縁 |
| `color/curtain` | `--ut-color-curtain` | `#141414` | `#F2F2F2` | 登場演出の幕（前景色と同じ） |
| `color/on-curtain` | `--ut-color-on-curtain` | `#F4F4F3` | `#111112` | 幕の上の名前 |

- **アクセントの代わり**: 今いる場所（タブ、分類ボタン、切り替え）は `fg` で塗った面に `bg` の文字で示す。リンクには下線を付ける。キーボード操作のフォーカスの枠は、`fg` の 2px の線を 2px 離して出す。
- `--ut-color-accent` はコードの仕組みに残っているので、`fg` と同じ値にする（名前だけ残す）。
- **コントラスト**: `muted` は試作の値（`#8A8A8A`、地に対して 3.14）が AA に届かないため、`#6B6B6B`（地 4.84、カード 5.33）に上げた。Dark の `muted` は地 5.71、カード 5.15。`fg` と地は両モードとも 16 以上。

## 7. 形・余白・影・トークン（Claude の提案）

- **角丸**: カード 16、横長カード 12、ボタン・切り替えの各項目 10、切り替え全体 12、シート上端 28、タブバー・丸ボタン 999（完全な丸）。
- **余白**: 4 の倍数（4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 56）。パソコンの中身の最大幅は 960（構造の設計書のとおり）。
- **境界**: 影は使わず、`color/border` の 1px の線で区切る。浮いている部品（タブバー、ツールバー、シート）にだけ、ごく薄い影 `0 8px 30px` 黒 8% を付ける。

色以外の値も、トークンとして名前を決めておく。Figma では数値の変数（コレクション `ut42tech/size`、モードなし）にし、コードでは `--ut-*` にする。イージングと時間は Figma に変数の仕組みがないので、コードのトークンだけにする。

| 種類 | Figma 変数 | `--ut-*` | 値 |
| --- | --- | --- | --- |
| 角丸 | `radius/card`、`radius/row`、`radius/control`、`radius/segment`、`radius/sheet`、`radius/full` | `--ut-radius-card` など同名 | 16 / 12 / 10 / 12 / 28 / 999 |
| 余白 | `space/1`〜`space/14` | `--ut-space-1` など | 4 の倍数（4〜56） |
| 中身の幅 | `width/content`、`width/reading` | `--ut-width-content`、`--ut-width-reading` | 960 / 720 |
| イージング | — | `--ut-ease-out`、`--ut-ease-rise`、`--ut-ease-curtain`、`--ut-ease-in-out` | 9 章のとおり |
| 時間 | — | `--ut-duration-fast`、`--ut-duration-base`、`--ut-duration-slow` | 180 / 250 / 600ms |

既存の `--ut-radius`（1つだけ）は、`--ut-radius-control` と同じ値の別名として残す。

## 8. すりガラス（試作で確認した値）

- 面: `color/glass`、背景のぼかし 22px、彩度 170%。
- 縁: `color/glass-line` の 1px 線、上端の内側に `color/glass-edge` の 1px のハイライト。
- 影: `0 8px 30px` 黒 8%。
- **代わりの表示**: ブラウザがぼかし（`backdrop-filter`）に対応していないとき、または「透明度を下げる」設定（`prefers-reduced-transparency`）のときは、`color/surface` の不透明な面にする。

## 9. 動き（試作で確かめた値）

共通の決まり:

- 動きの原則は、構造の設計書 3 章の4つ（すぐ反応する／動きがつながる／意図に応える／遊びを加える）。
- **イージング**:
  - `ease-out`: `cubic-bezier(.2, .8, .2, 1)`。ほとんどの動き。
  - `ease-rise`: `cubic-bezier(.2, 1, .3, 1)`。文字が上がる。少しだけ行き過ぎて戻る。
  - `ease-curtain`: `cubic-bezier(.76, 0, .24, 1)`。幕。
  - `ease-in-out`: `cubic-bezier(.7, 0, .3, 1)`。幕の上の名前が抜ける。
- **ばね**: 文字がポインターへ寄る動きは、ばね（硬さ 160、減衰 20、1 秒あたり）で動かす。
- 「視差効果を減らす」（`prefers-reduced-motion`）では、下で「減らす設定」と書いたとおりに動きを止めるか、置き換える。

### 9.1 登場演出

| 時刻（ms） | 動き |
| --- | --- |
| 0 | 画面全体を `color/curtain` の幕が覆っている（5本の縦の帯） |
| 80 | 「Takuya Uehara」が下からせり上がる（600ms、`ease-out`、文字の高さ分の窓から現れる） |
| 780 | 名前が上へ 24px 抜けながら消える（500ms、`ease-in-out`。不透明度は 350ms） |
| 780 | 5本の帯が、左から 60ms ずつ遅れて上へ抜ける（各 820ms、`ease-curtain`） |
| 1060 | 「Welcome.」が1文字ずつ下から上がる（各 900ms、`ease-rise`、1文字 45ms ずつ遅らせる。0.35em 下から） |
| 1660 | 「to ut42tech」がふわっと現れる（600ms） |
| 1930 | 幕を取り除く |

- **見せるのは1回の訪問で最初だけ**（タブを閉じるまで記憶する）。2回目以降のページの読み込みでは出さない。
- **いつでも飛ばせる**: キー入力、ホイール、タップで、その場で完成した状態にする。
- **待たせない**: 書体の読み込みを最大 1.5 秒まで待つ。それを超えたら、読み込みを待たずに幕を上げる。
- **減らす設定**: 幕は 400ms でふわっと消すだけ。あいさつは最初から出しておく。
- **Hello 以外のページから入ったとき**（共有されたリンクで `/works/apps/<slug>` などを直接開いた場合。Claude の判断）: 幕と名前は同じように出し、幕が上がった先はそのページにする。「Welcome.」の演出は Hello でだけ起こす。

### 9.2 Hello のあいさつ

- 「Welcome.」の各文字は、ポインターとの距離が 420px 以内のときに、ポインターの方へ寄る。
  - 寄る量は横に最大 14px、縦に最大 10px で、近いほど大きい。
  - ばねで動き、ポインターが 2.5 秒止まると元の位置に戻る。
- 文字を押すと、全体が上に軽く弾む（各文字に上向きの初速 260〜320px/s を与え、同じばねで戻す）。
- 読み上げ用に、文字をまとめた見出し（`aria-label="Welcome."`）を置く。1文字ずつの要素は読み上げない。
- **減らす設定**: 寄る動きも弾む動きもしない。

### 9.3 パソコンのポインター（ipad-cursor 0.5.2）

- マウスなど細かく指せる端末（`pointer: fine`）でだけ使う。タッチ端末では使わない。
- 押せる要素には `data-cursor="block"` を付ける。
- 設定:

```js
initCursor({
  normalStyle: { background: 'rgba(127,127,127,.28)', backdropBlur: '0px' },
  blockStyle: { background: 'rgba(127,127,127,.14)', radius: 'auto', durationPosition: '0.2s' },
  textStyle: { background: 'rgba(127,127,127,.5)' },
  enableAutoTextCursor: false,
  enableMouseDownEffect: true,
  enableLighting: true,
})
```

- 画面の中身が入れ替わったら（シートの切り替え、Works の分類の切り替えなど）、`updateCursor()` を呼ぶ。Vue の部品では `ipad-cursor/vue` の `useCursor` を使う。
- ライブラリの最後のリリースは 2023-07。不具合が出たら、手元に取り込んで（フォークして）直す前提で使う。
- **減らす設定**: ライブラリを読み込まず、OS の標準のポインターにする。

### 9.4 画面の移り変わり（Claude の提案。試作していないので、実装時に触って調整する）

- **シートがせり上がる**: ばね（硬さ 380、減衰 34）で、行き過ぎはほとんどない。閉じるときも同じばねで、指を離したときの速さを引き継ぐ。
- **払って閉じる判断**: 指を離した位置に、慣性で進む距離を足して判断する（1ms あたりの減衰率 0.998）。予測した位置がシートの高さの 1/3 を越えたら閉じる。
- **カードから Apps の詳細へ**: サムネイルが広がる動きは、ブラウザの画面遷移の機能（View Transitions）で、360ms・`ease-out` にする。払って閉じるときは、指の速さのまま元のカードへ戻す。画面の外へ投げる遊びは、予測した位置が画面の外になったときだけ起こす。
- **切り替え・分類ボタンで中身を入れ替える**: 古い中身が 120ms で消え、新しい中身が 8px 下から 200ms で現れる（`ease-out`）。
- **詳細の上に半分のシートを重ねる**: 裏の詳細を 250ms で暗くし（黒 25%）、シートは上と同じばねで上がる。
- **減らす設定**: どれも 150ms のふわっとした切り替えにする。

### 9.5 押したときの反応

- スマホのタブ・ボタン: 押している間、`scale(.92)` に沈む（180ms、`ease-out`）。
- 選択中の表示の切り替え（タブ・分類ボタン・切り替え）: 背景色と文字色を 250ms で変える。

## 10. Figma で作るもの

既存のファイル `ut42tech — Portfolio` を使う。

1. **変数**: 5 章の表のとおりに `ut42tech` コレクションを作り直す。7 章の数値の変数（`ut42tech/size`）も作る。
2. **文字スタイル**: 6 章の表のとおりに作る。
3. **部品**: ワイヤーフレームの部品（`WF/*`）を元に、本番の見た目の部品 `UI/*` を作る。色は変数に、文字は文字スタイルに結び付ける。
   - タブバー、ツールバー、シート、切り替え、分類ボタン、並び替え、表示の切り替え、カード、横長カードが対象。
   - タブバーとツールバーはすりガラスにする。シートは不透明な面にする。
   - アイコンは Lucide の SVG を取り込み、色は `color/fg` か `color/muted` に結び付ける。
   - カードと横長カードは、画像あり／フォールバックの2種類を持つ。
4. **画面**: 新しいページ `Visual — Mobile` と `Visual — Desktop` を作る。
   - 両方: 登場演出の幕（名前が出た状態）、Hello、About、Works（Apps）、Apps の詳細、Works（Career）、Press。
   - スマホだけ: Press の半分のシートを詳細の上に重ねた状態。
   - 各ページで、Hello と Works（Apps）だけは Dark の版も並べる。
5. ワイヤーフレームのページはそのまま残す。

## 11. 実装者に任せること

- 5〜7 章の値のうち、画面に当てて違和感が出たものの微調整。ただし、コントラストが AA を下回る変更はしない。
- Figma のフレームの並べ方と、注記の書き方。
- 仮の画像の作り方。モノトーンの UI の中で、写真に色がある状態を見せるため、仮の画像は色付きにする。
